# Code Canvas

Code Canvas is a platform that helps developers understand algorithms by **visualizing how code executes step by step**.

> Code is intent executing over time — Code Canvas makes that execution visible.

###### Live Demo: [canvas.chetansatpute.dev](https://canvas.chetansatpute.dev)

## Why this project exists

Many developers can read algorithm implementations but struggle to visualize what actually happens during execution.

Code Canvas focuses on making **program execution understandable**, not just readable.

## What it does

- Line-by-line algorithm execution
- Visualization of data structure evolution
- Code highlighting synchronized with execution
- Interactive learning experience for algorithms

This project explores ideas around **developer education and visualization-driven learning**.
